LightMate

Made for machines everyone else gave up on

Laptops and desktops from the Core 2 Duo era still work fine for browsing, writing and video, if the system on them stays out of the way. LightMate keeps the classic MATE desktop and drops everything that is not needed to use it.

It is a small, personal project. The first release, v0.1, is out, so expect rough edges and please report what breaks.

Not sure if your 32-bit PC has PAE? Boot any Linux live USB and run grep -c pae /proc/cpuinfo. A result above 0 means it does. Some Wi-Fi chips (for example Broadcom) need extra non-free firmware that is not included by default.

Build it yourself

You need a Debian or Ubuntu machine (a VM is fine) with about 15 GB of free disk space, 4 GB of RAM and an internet connection.

LightMate is made with Debian's live-build. Run these on a Debian or Ubuntu machine and you get a bootable ISO. Use a separate folder for each architecture.

sudo apt install live-build
mkdir lightmate && cd lightmate
lb config --distribution bookworm \
  --architectures i386 --linux-flavours 686-pae \
  --binary-images iso-hybrid \
  --archive-areas "main contrib non-free non-free-firmware" \
  --apt-recommends false \
  --bootappend-live "boot=live components quiet splash"
mkdir -p config/package-lists
printf '%s\n' mate-desktop-environment-core lightdm \
  lightdm-gtk-greeter network-manager-gnome \
  epiphany-browser firmware-iwlwifi \
  > config/package-lists/lightmate.list.chroot
sudo lb build

What LightMate aims for

These are design goals. There are no benchmark numbers yet.

  • Only what you need is installedRecommended packages are switched off, so the system contains what is listed and nothing extra.
  • A plain login and desktopLightDM and MATE with the Marco window manager, without heavy visual effects.
  • Sensible memory useCompressed swap in RAM (zram) so machines with a few GB do not stall.
  • Both architectures, one recipeThe same config builds 32-bit and 64-bit images.
  • A browser that fits each buildThe 64-bit image ships Firefox ESR. The 32-bit image ships Epiphany (GNOME Web), because Firefox no longer supports 32-bit Linux.

Known issues

Some older laptops only boot with ACPI turned off. At the boot menu press Tab (BIOS boot) or e (UEFI boot), replace quiet splash with acpi=off, then boot. Power management is limited in this mode.

On the 32-bit build, browser choice is limited: Firefox and Chrome no longer support 32-bit Linux. Epiphany gets updates through Debian, but it has fewer add-ons and can struggle with heavy web apps. If your PC can run 64-bit, use the 64-bit build.
